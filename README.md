# Ӏакъидатан Академия — Telegram Mini App

Первая рабочая версия интерфейса без реальных материалов курса.

## Что уже есть
- Главная
- Курсы и список уроков
- Экран урока
- Тестовый аудиоплеер
- Место для начального текста
- Место для PDF
- Поиск
- Избранное
- Прогресс
- Профиль и настройки
- Светлая и тёмная тема
- Сохранение избранного и прогресса на устройстве

Реальные материалы из Telegram-канала будут добавлены позже после проверки дизайна и функций.
